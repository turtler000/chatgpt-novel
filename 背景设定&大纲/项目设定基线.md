## 一、作品总体定位

### 核心类型
- 近未来 / 低烈度星际文明背景下的军事政治小说。
- 科技水平存在明显断层：
  - 帝国常规工业、陆军、航空兵：约比当代地球先进半代到一代。
  - 商业共和国及其大公司：常规技术明显领先，AI、无人化、机器人化、信息化程度很高。
  - 星际航行与部分战略技术：来源于更高文明遗产或对遗产技术的二次开发，明显超出双方普通科技树。
- 帝国本身是成熟工业国家和区域强国，只是在更大的星际体系中相对落后。

### 核心主题倾向
- 战争不是善恶双方的决战，而是多个政治实体利用战争交换资源、转移矛盾、制造谈判筹码。
- 军事上的胜负与政治上的胜负并不一致。
- 国家、公司、贵族、军队和普通人的“成本函数”不同。
- 国家机器可以真诚宣称保护人民，同时把具体的人当作可承受成本。
- 人物不追求简单的“觉醒后推翻一切”；更多是在理解规则后学会使用规则。

## 二、星际政治大框架

### 1. 松散联邦 / 共同安全组织
性质类似：
- 北约式共同防务框架
- 联合国式成员政治协商
- 国际仲裁 / 条约监督体系

成员包括帝国、商业共和国及其他具备星际航行能力的文明或政治实体。

### 2. 联邦存在的现实基础
- 联邦外部存在长期安全压力：
  - 其他同级星际政治体；
  - 更高等文明；
  - 未知异常区 / 遗产系统等。
- 所以成员内部可以冲突，但不能严重消耗整个联邦的战略力量。
- 联邦不是伟光正的超国家政府；平时政治交易、偏袒、票数和成员实力都很重要。
- 共和国对联邦共同防务、舰队、贸易与技术体系贡献较大，因此平时话语权强于帝国。
- 但涉及最高等级战略违规时，联邦必须程序上公正严明，否则共同安全体系会失去可信度。

### 3. 联邦内部战争强度
建议保留“五级事件”概念：
- 低级别：治安、边境摩擦、私人安保冲突。
- 中级别：有限地面正规战争，可使用陆军、航空兵和普通常规武器。
- 更高级：轨道力量直接军事介入。
- 五级：遗产级航行技术直接武器化、恒星级战略资产互相攻击等。

核心原则：
> 平时可以政治，五级必须讲规则。

### 4. “航路不得成为兵器”
共同协议的核心精神：
- 恒星级航行能力是联邦共同安全与对外生存能力的一部分。
- 成员内部有限战争不得把恒星航行能力直接转化为战略杀伤优势。
- 普通轨道导弹、动能武器甚至核武器虽然也属于严重升级，但仍是“大家理解并有成熟规则的战争工具”。
- 遗产级空间投射属于性质完全不同的红线：它是把恒星航行能力本身武器化。

## 三、帝国

### 1. 国家形态
- 古典军事帝国进入工业社会后的延续。
- 高度工业化、中央财政和军队基础设施强大。
- 皇权逐渐弱化，皇帝保留强烈象征性与最终合法性签署权。
- 皇帝更像国家合法性最后节点，而非日常独裁统帅。

### 2. 星系结构
- 帝国主要控制一个恒星系。
- 内缘行星：
  - 统一较早；
  - 人口、工业、军校、贵族政治、中央机构集中；
  - 帝国核心。
- 外缘行星：
  - 后来通过军事统一逐步并入；
  - 法律上已是帝国正式组成部分，不是简单殖民地；
  - 资源型经济较强、基础设施与政治资源弱于核心；
  - 本地身份与帝国身份可以并存。

### 3. 主角所在外缘行星
- 本地人在政治文化上大体接受帝国身份。
- 同时保留鲜明本地认同。
- 本地经济高度依赖公司矿业。
- 主角可以同时认为：
  - “我是本地人”
  - “我是帝国人”
  - “我靠公司矿场吃饭”
  三者并不矛盾。
- 法律上本地人是正式帝国人口；真正的不平等主要体现在中心—外缘资源差异。

## 四、帝国贵族 / 门阀制度

### 1. 核心性质
爵位更接近：
- 世袭政治资格；
- 家族历史信用；
- 贵族大会中的政治权；
- 进入帝国权力中心的门票。

“封地”主要是：
- 荣誉性领地；
- 庄园；
- 仪典地位；
- 少量收益。

财政、司法、地方军政大权不与封地绑定。

### 2. 公侯伯三层

#### 公爵
- 全帝国仅 3—4 家。
- 极度古老，接近皇室与国家象征。
- 权力高度符号化，不适合长期直接把持具体部长或军队职位。
- 在皇位、重大授爵、宪制危机、战争等问题上具有极高象征性权重。

> 公爵代表帝国“是什么”。

#### 侯爵
- 十几家左右。
- 真正的帝国门阀与权力中心。
- 通过家族网络、政治代理、人脉、婚姻、军政传统影响：
  - 国防部
  - 外交系统
  - 总参谋部
  - 舰队高级指挥层
  - 关键委员会
  - 行星行政与军工体系

> 侯爵决定帝国“往哪走”。

#### 伯爵
- 数量最多，几十家。
- 包括古老军功家族和较新的军政新贵。
- 贵族层最有流动性的一层。
- 最焦虑，也最积极争军功和家族续存。

> 伯爵争夺帝国“谁能进来”。

### 3. 爵位升降
- 爵位绑定跨代公共服务 / 军功。
- 定期召开皇族与贵族大会审议：
  - 新家族入爵；
  - 伯爵升侯；
  - 旧家族降爵；
  - 极少数顶层变动。
- 通过后，由皇帝签署。
- 贵族子弟因此有强动力进入军队、军政、国防相关体系。
- 寒门军官也可凭长期军功和政治背书让家族进入贵族席位。

### 4. 灰色交换机制
- 寒门将领有军中资源，缺政治资本。
- 贵族有政治票和门阀网络，缺新的真实军功。
- 双方互利：
  - 贵族子弟得到更容易立功的岗位和机会；
  - 寒门将领得到授爵审议中的支持。

核心句：
> 军官帮贵族把政治资本洗成军功；贵族帮军官把军功洗成爵位。

## 五、少爷家族

### 1. 定位
- 侯爵家族。
- 不是象征性公爵，而是实际军政门阀。
- 可以起源于约两百年前帝国第二轮外缘扩张，一位军人祖先凭关键战役从伯爵晋侯。

### 2. 家族传统
长期三条路线：
- 军队 / 总参谋体系；
- 外交、国防、贵族院；
- 军工、遗产技术、军校等半技术政治机构。

家族真正值钱的不是侯爵本人，而是：
- 退役上将；
- 军校校长；
- 姻亲财政家族；
- 贵族院委员会；
- 长期扶持的寒门军官；
- 与其他伯爵家族的政治互信。

### 3. 政治风格
- 职业军政派。
- 尊重军队专业主义。
- 支持军事贵族持续履行公共责任。
- 乐于吸收有能力的寒门军官进入贵族阶层。
- 现实主义，不是纯鹰派。

### 4. 少爷与家族的矛盾
少爷反感：
> “凭什么我们出生在这个家里，就能判断一个打了三十年仗的人配不配进门？”

因此：
- 正儿八经军校高材生；
- 不愿吃家族资源；
- 本可去中央师 / 军部参谋安全镀金；
- 非要进入本地师基层作战单位。

后来为救主角，他第一次主动回到门阀政治中，推动家族正式支持中将入爵。

## 六、中将

### 1. 基本身份
- 寒门职业军官。
- 原为中央师少将师长。
- 战绩不错，刚晋升中将，接任本次地面军军长。
- 中央师是他的老底子。
- 两个本地扩编师和大量资源，是中央给他的战争筹码。

### 2. 性格
- 极端自律。
- “无情的战争机器”。
- 早餐西兰花、燕麦、健身餐。
- 背负祖辈期待。
- 唯一私人宏愿：让家族进入正式贵族席位。
- 战争与组织能力极强，政治手腕却比较笨拙。

能力分布：
- 打仗：极强
- 读战报 / 判断敌意图：极强
- 军队组织：极强
- 首都政治：一般
- 秘密清洗 / 黑箱政治：很差

### 3. 战争中的作用
- 接手时帝国此前长期不愿与公司正面对打。
- 他看懂公司成本结构，敢接受极高帝国伤亡。
- 不是简单人海，而是在确认：
  - 帝国装备可本地补充；
  - 本地兵员可持续扩充；
  - 公司高科技人员与设备补充困难；
  - 公司更加珍惜人命。
- 他逐步改变帝国打法，使地方师真正学会对抗公司。

### 4. 发现异常矿区
在一次晨间长战情汇报中：
- 发现某交通点伤亡数据异常；
- 绝对伤亡并不夸张；
- 但来自他非常了解、已经适应公司打法的得力部队，因此“不符合行为模型”。
- 立刻通电话、调地图；
- 发现节点连接一处不起眼、早已停产的地下矿区。
- 判断公司在守某种极重要资产，但不知道存在超自然异常。

### 5. 轨道炮后
- 公司一炮后，他迅速：
  - 停止主动进攻；
  - 要求轨道力量不得先还击；
  - 封存记录；
  - 让第三师救援但不继续深入核心区。
- 确认联邦战略冻结、不会有第二炮后，他认为自己的战争结束。
- 回办公室躺椅睡约两小时。
- 秘书推门叫醒：
  - 确认是遗产级空间投射；
  - 皇帝已签署最高等级联邦弹劾程序。
- 他罕见说：
  > “……卧槽。”

### 6. 战后清理线
一开始他觉得自己很干净：
- 战争合法；
- 41团行动属正常作战；
- 他不知道地下异常；
- 舰炮是公司自行发射。

后来压力叠加：
- 首都政治掮客；
- 外交体系；
- 外缘地方官员；
- 贵族院；
- 共和国隐性要求；
- 自己的进爵前景。

最终接受“处理41团风险”，但不擅长政治脏活，把目标当军事任务下给安全体系，导致执行过度。

不能洗成“完全是下属误解”：
- 他知道自己在干什么；
- 只是想拿结果，又不愿深究手段。

## 七、主角

### 1. 身份
- 外缘行星根正苗红的本地土著。
- 文化与国家身份倾向帝国。
- 经济生活依赖公司矿场体系。
- 帝国扩军后被征召。

### 2. 特殊能力
- 有轻微“灵能 / 特殊感知”。
- 前期主要表现为：
  - 危险直觉；
  - 异常空间 / 生命感知；
  - 难以解释的战场预感。
- 不影响大战走向。
- 主要作用：
  - 个别战场事件提前感知；
  - 解释轨道炮后为何偏偏活下来；
  - 后续连接更大的遗产 / 异常设定。

### 3. 人物路径
- 本地普通青年
- 征召兵
- 正规战士
- 与少爷、老士官成为战友
- 轨道炮事件幸存者
- 战争英雄 / 不存在的战争英雄
- 联邦调查潜在证人
- 被帝国安全体系压迫
- 被逼武装反抗
- 被定义为恐怖分子
- 最终被少爷通过贵族政治资源换得一条命

主角不要轻易“反帝国觉醒”。
即使被追杀，他仍可能认为：
> “我忠于帝国，是这些人在背叛帝国。”

## 八、少爷

### 1. 身份
- 侯爵家族子弟。
- 军校高材生。
- 入伍即为上尉副连长，起点明显高于普通军校毕业生。
- 原本合理路线是中央师 / 司令部 / 参谋体系。
- 主动拒绝“吃肉”，进入本地临时扩编师基层作战单位。

### 2. 性格主轴
- 对贵族特权有强烈道德不适。
- 试图证明“不使用特权就能和普通人一样”。
- 战争后逐渐意识到：
  > 不使用特权，并不会让特权消失。

### 3. 发展
- 初战时知识正确，但缺乏实战经验。
- 经第一次惨败成长为真正基层军官。
- 与老士官经验、主角本地感 / 灵能逐渐互补。
- 轨道炮中重伤但幸存。
- 战后凭真实军功回到首都。
- 最后为了救主角，第一次主动使用家族政治资源：
  - 推动家族支持中将家族入爵；
  - 给中将送去“入场券”；
  - 条件是主角的事到此为止。

---

## 九、老士官

### 1. 身份
- 中央军体系职业士官。
- 十年前曾与公司发生过小规模作战。
- 是主角基层成长的真正老师。
- 建议设为排军士长，更贴近主角。

### 2. 功能
- 代表战争经验和军队基层骨架。
- 少爷有理论，老士官有经验，主角有本地与异常感知。
- 初战时军官链失灵后，他是带队活下来的关键人物。
- 后期不能永远正确，因为公司十年技术升级也超出他的旧经验。

### 3. 去向
倾向：死于轨道炮事件。
- 不必壮烈牺牲。
- 他的死亡象征：
  - 主角和少爷已经学会“正常战争”；
  - 接下来进入旧战争经验不能解决的阶段。

## 十、待建立的重要角色

1. 第三师师长
   - 中央正规军高级军官。
   - 保护自己本地师的精锐和战斗力。
   - 对中将“把地方师当资源”有隐性不满。
   - 中将要他给一支精锐，他阳奉阴违把主角所在团派去异常点。

2. 公司轨道空降旅旅长
   - 高度职业化。
   - 极重视人员损失。
   - 不知道地下异常项目。
   - 从未申请舰炮。
   - 轨道炮绕过其指挥链，把仍在交火的己方人员一起炸死。

3. 公司异常项目员工 / 风险值守员
   - 发现帝国军进入异常区。
   - 只是按照手册触发最高等级内部警报。
   - 不直接下令开炮。
   - 事件经过特殊风险链越过地面军方，直达舰队。

4. 帝国军务安全 / 宪兵负责人
   - 战后真正执行“处理41团”。
   - 可以成为持续反派。
   - 崇拜中将，认为自己替军长做必要脏活。
   - 把模糊政治要求军事化、极端化。

5. 联邦裁判席调查员
   - 不伟光正。
   - 对战争正义兴趣有限。
   - 单纯职业性较真。
   - 本来只是来完成五级事件强制审计。
   - 坚持追问：
     > “这一炮到底为什么打在那里？”

6. 政治掮客 / 协调人
   - 战后负责把首都真实意图送给中将。
   - 可以分成：
     - 国防 / 战区军政协调专员
     - 侯爵家族政治代理
     - 皇室 / 宫廷书记系统
     - 外缘地方议会领袖
   - 他们通常不下正式命令，只“递话”“提醒”“表达担忧”。

## 十一、帝国地面军编制

### 本次战争规模
中将指挥约 5—6 万人。

主力：
- 1个中央师
- 2个外缘本地战时扩编师
- 军直属航空、炮兵、工程、通信、电子战、后勤、医疗等

### 正式层级
主干：
> 军 → 师 → 团 → 连

基层仍有：
> 连 → 排 → 班

不设永久“营”一级。

团通过临时“战斗群”完成营级功能：
- 副团长带若干连 + 装甲 / 工程 / 炮兵组成临时任务群。

### 班
约 8—10 人，建议 9 人。
核心是职业士官。

### 排
约 30—40 人。
- 3个班
- 排长
- 排军士长
- 通信
- 医疗
- 火力 / 无人机支持

### 连
约 120—180 人，建议 150 人上下。
- 连长
- 副连长（少爷）

## 十六、战争原因

### 公司真实战略

### 帝国表面理由

- 恢复帝国主权；
- 限制私人武装；

### 帝国根本政治目标
- 国内矛盾需要出口；
- 军功贵族体系需要战争流动机会；
- 争取矿业利益；
- 恢复边疆国家存在；
- 最重要：地面打出成绩，迫使公司先动用更高等级轨道力量，从而取得联邦调停中的政治筹码。

中将的真正任务：
> 创造有利于外交解决的军事态势。

## 十七、战争阶段

### 第一阶段：帝国高伤亡推进
- 公司仍守大量外围资产。
- 帝国用正规装甲、炮兵和人员规模持续推进。
- 交换比难看，但地图不断变色。
- 公司每天宣称杀伤大量帝国军。
- 帝国每天宣称收复大量矿区。
- 双方战报都是真话，也都在骗人。

### 第二阶段：公司收缩，战争僵持
公司放弃外围资产，集中守：
- 核心矿区
- 维修中心
- 轨道物流
- 山口
- 工业堡垒

结果：
- 公司人员减少，但防线密度上升；
- 帝国推进显著变慢；
- 中将停止按面积评价战果；
- 开始专打公司体系的不可替代节点；
- 公司开始武装民用工业机器人。

### 第三阶段：异常节点
中将发现某不起眼交通点公司投入不符合正常成本逻辑。

要求第三师派一支可靠精锐去摸。

第三师师长阳奉阴违：
> “你中央师不动，凭什么掏我的王牌？”

于是派主角所在团。

这个团：
- 已适应公司战法；
- 靠谱；
- 但不是师长真正核心精锐；
- 位置又近。

结果误打误撞进入地下异常矿区。

## 二十四、舰炮 / 遗产级空间投射武器

### 技术底层

- 帝国主要会“使用”。

### 武器形态

载荷内部包括：
- 空间稳定与约束设备
- 结构
- 定位 / 安全系统
- 数十克级反物质高能战斗部

### 一炮即可
只发一炮。

目标：
> 地下异常 / 污染核心区，而非帝国军本身。

投射舱进入公司掌握精确三维结构的地下大型空腔；
反物质释放，从地下内部摧毁整片结构。

### 战术反常
- 公司地面人员没有撤离。
- 双方仍在交火。
- 地面旅长不知道会开炮。
- 舰炮不是旅长申请的。
- 指令通过公司特殊风险系统越过地面军方，直接到舰长和操作人员。

这证明：
> 触发优先级高到可以覆盖公司平时极度珍惜人员生命的原则。

> “单次、特殊、未经常规军事链充分审查的遗产级紧急处置事件。”

### 阶段4：联邦强制技术审计
政治问题解决后，五级事件仍必须接受事后审计。
调查团几周或一个多月后抵达。

---

## 二十八、共和国对联邦调查的口径

使用“八成真、两成关键假”：

地下存在：
> 高风险遗产技术工业设施 / 空间场试验设施。

帝国军突破后：
- 设施进入不可回收状态；
- 存在重大安全风险；
- 常规攻击不足以保证销毁；
- 因而依据旧紧急协议执行一次遗产级处置。

共和国主动承认：
- 程序与现行战争规则衔接不足；
- 未充分考虑地面友军；
- 授权链存在制度缺陷。

主动：
- 冻结权限
- 暂停旧协议
- 找程序责任人负责
- 赔偿
- 改规则

绝不承认：
> 公司在非法研究 / 隐瞒一个体系外异常，并开炮灭证。

核心策略：
> 承认过度反应，绝不承认真实动机。

## 二十九、为什么帝国后来也不想深究

帝国最初当然想查到底，但逐渐意识到：

1. 若确认地下是联邦最高等级异常：
   - 区域可能进入联邦共同监管；
   - 帝国刚打回来的矿区可能失去控制。

2. 公司会获得更好辩护：
   - “这不是战争升级，是异常安全处置。”

3. 主角团变成“接触人员”：
   - 可能被隔离；
   - 外缘行星甚至面临封锁 / 监控。

4. 中将履历可能被重新解释为：
   - 未授权闯入高危遗产区；
   - 战略判断冒险。

5. 帝国自身可能已有灵能 / 异常个体档案，不想被联邦顺藤摸瓜。

所以帝国最优策略：
> “非法使用遗产武器”这张必赢牌已经够了，不要继续开盲盒。

## 三十、主角团清理的最终政治逻辑

更强版本：

清理压力主要来自共和国。

双方交换政治资源、帝国准备撤销最高联邦弹劾时，共和国提出隐性条件：

> “炮击区一手接触人员不能成为后续联邦审计中的不可控风险。”

不会正式写“杀掉他们”。

正式文件只会写：
> “双方承诺妥善处置战略事件相关敏感信息，避免未经核实材料影响联邦审计。”

帝国政治层理解真正含义。

共和国给：
- 矿权
- 赔偿
- 重建基金
- 联邦政治支持

帝国不愿为几百名士兵推翻国家收益。

压力链：
共和国 → 帝国外务系统 → 国防 / 政治掮客 → 中将 → 军务安全负责人

每传一层，语言更文明。

## 三十一、中将战后政治压力与清洗失控

中将初期：
> “查就查，我很干净。”

甚至可能反对动主角团。

随后：
- 首都提醒协议风险；
- 地方政府怕矿区重新冻结和失业；
- 贵族政治代理暗示入爵可能延期；
- 共和国要求成为谈判的一部分。

中将逐步接受：
> “这件事必须结束。”

但他只会打仗，不懂秘密政治操作，因此给安全体系下达过于军事化的模糊目标。

安全负责人开始：
- 集中审查幸存者
- 限制通信和行动
- 抓捕试图接触联邦的人
- 制造军纪 / 泄密案件
- 个别人员失踪、死亡

幸存者开始反抗。

主角营救战友 / 袭击押运 / 劫人。

安全部门重新定义：
> “主角团残部已成为战后极端武装。”

## 三十二、少爷救主角

少爷回到首都后获得真实战争军功。

当主角被追杀后，他第一次主动进入家族政治。

推动家族正式决定：

> “支持中将家族在下一次贵族大会进入席位。”

同时传达：

> “这件事到此为止。”

不是感情长信，而是简短、正式、政治化的承诺。

对中将意义巨大：
- 入爵是他一生目标；
- 一个侯爵家公开支持，意味着一个小型票仓；
- 若继续杀主角，可能反而失去入场券。

所以中将：
- 停止主动追捕；
- 降低案件等级；
- 把主角从军方最高优先级目标中移除。

主角未获公开平反，只是突然发现：
> 追他的人少了。

## 三十三、战争叙事原则

### 不要写成参谋教材
完整军事设定只作为作者底盘。

正文优先通过具体东西表现：
- 假团部
- 被拼回来的旧步战车
- 没批准下来的空袭
- 公司拼命抢一个伤员
- 装卸机器人被焊上枪
- 新兵不会躲无人机
- 士官叫人关终端
- 战友被精准打掉

### 主角视角
主角不会知道：
- 公司库存曲线
- 中将完整战略指标
- 联邦政治全貌

他的体验是：
> 第一次不知道敌人在哪；
> 后来我们会打了；
> 再后来突然出现一个所有经验都解释不了的东西。

## 三十五、核心设定锚点

> 帝国拥有战争机器，公司拥有战争按钮。

> 公司赢很多接触战，帝国打整场战争。

> 诱饵不是要像真的，而是要贵到值得敌人验证。

> 战争期间，制服暂时把他们变成战友；战争结束后，社会结构把他们弹回原来的位置。

> 中将不是不知道生命值钱，而是非常准确地知道两个社会分别给一条命标了多少钱。

> 公爵代表帝国是什么；侯爵决定帝国往哪走；伯爵争夺帝国谁能进来。

> 少爷最初以为不用特权就是高尚，最后发现不用它并不能让特权消失。

> 调查员不是来主持正义的，他只是想知道那一炮为什么打在那里。

> 帝国和共和国最后真正害怕的，不是彼此，而是有人坚持把已经够用的真相继续查下去。

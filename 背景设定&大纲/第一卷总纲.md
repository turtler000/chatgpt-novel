# 外缘战争｜第一卷总纲 v0.1

> 卷名暂定：《外缘战争》
>
> 定位：第一卷不是“把战争打完”的流水账，而是一条完整的人物命运弧——主角从外缘普通青年被卷入战争，在战争中学会成为军人；等他终于理解并适应战争，战争却被更高层级的政治与异常力量突然终止；随后他又从“战争英雄”变成需要被处理的人，最终离开外缘，转入帝都。
>
> 章节规模暂按 150—170 章设计，仅作为体量感，不锁死章号。每个阶段至少给足约 20 章的正文空间，阶段内部再拆 3—6 个小剧情单元。

---

## 一、第一卷的核心承诺

第一卷给读者的不是单纯“打仗升级”，而是三层体验同时推进：

1. 战争成长线  
   一个第一次上战场的人，从“根本不知道敌人在哪”到“我们终于会打了”。

2. 人物关系线  
   主角、少爷、老士官从陌生的军队关系变成真正的战友；随后战争结束，原本被制服暂时抹平的社会差异重新出现。

3. 大世界悬念线  
   一场本来可以被理解的有限战争，逐渐露出无法用常规政治、军事和技术解释的东西。真正的大悬念不是“谁赢了”，而是：
   > 公司为什么宁愿违反最高等级联邦规则，也必须把那个矿坑炸掉？

第一卷卷尾完成一个身份转换：

> 外缘普通人 → 征召兵 → 正规士兵 → 老兵 → 炮击幸存者 → 潜在证人 → “极端武装”成员 → 被政治交易暂时放过的人 → 前往帝都。

---

# 第一阶段｜入伍

### 预计体量
约 1—22 章。

### 阶段任务
建立“战争以前的世界”，让读者先认识主角生活的外缘社会，再认识军队。

这一段不能写成二十章军训流水账。训练只是场景，真正要写的是：
- 外缘居民如何看帝国；
- 本地人与公司矿业体系的现实关系；
- 战争宣传与普通人的距离；
- 临时扩军带来的混乱；
- 新兵之间的关系；
- 主角、少爷、老士官三人如何碰到一起；
- 一个地方青年第一次进入正规军事组织后的新鲜、荒谬和压迫感。

### 主要剧情
- 公司收缩项目、设备和人员，地方社会开始出现不安。
- 帝国加强对矿区、运输与安全体系的介入。
- 主角被征召。
- 离开原有生活圈，进入第三师的新兵与补充训练体系。
- 认识同期士兵，形成最初的小群体。
- 少爷以年轻上尉、副连长身份出现。
- 老士官作为真正负责把人训练到能活着上战场的基层骨架出现。
- 少爷与老士官在训练方法上有小冲突，但不是“菜鸟军官被老兵打脸”，而是两套都有合理性的知识体系发生摩擦。
- 主角特殊感知只出现很轻的痕迹，甚至可以被解释为紧张、运气或本地经验。
- 部队完成训练、整编、装备接收，正式向矿带前线移动。

### 情绪曲线
日常 → 新鲜 → 群体关系升温 → 对战争的模糊兴奋 → 不安逐渐增加。

### 阶段结尾
不急着打一场完整大战。

更适合用“真正进入战区”收尾：
- 公路边第一次看见被精准打穿的装甲车辆；
- 无人机警报第一次响起；
- 老兵突然要求所有人关闭终端；
- 远处出现第一轮真实炮火。

让主角意识到：

> 前面的训练，到这里才结束。

# 第二阶段｜第一次失败

### 预计体量
约 23—46 章。

### 阶段任务
把主角以及读者之前建立的“战争常识”全部打碎。

这不是一场两三章结束的惨败，而是一场逐层失去控制的战役。

### 前半段
- 前线巡逻与小规模接触。
- 帝国并非完全挨打，也能依靠炮兵、装甲和人数取得局部成果。
- 新兵第一次杀人、第一次见战友死亡。
- 少爷最初的命令大部分其实是正确的，因此失败不能靠把他写蠢来完成。
- 公司逐步暴露真正的信息优势。

### 战役升级
主角所在团与公司一个满编营发生正规遭遇。

公司不以消灭前线步兵为第一目标，而是逐步切断：
- 观察；
- 通信；
- 炮兵链；
- 指挥节点；
- 车辆与补给调度。

帝国士兵并没有成片被杀死，但“团”这个组织开始消失。

### 三人表现
- 主角第一次靠危险直觉救下少量人员，但无法改变战局。
- 少爷经历“命令正确却无法生效”的挫败。
- 老士官成为指挥链崩溃后，真正把一群人带回来的核心人物。

### 战后
必须给失败留足余波：
- 撤退；
- 找失踪人员；
- 战地医院；
- 幸存者名单；
- 战损统计；
- 军官被调查；
- 原团后撤整补；
- 主角养伤；
- 同期新兵第一次出现永久缺席的位置。

### 情绪曲线
紧张 → 接敌兴奋 → 困惑 → 失控 → 恐惧 → 求生 → 麻木 → 低谷。

### 阶段核心认识
不是：
> “公司太强了。”

而是：
> “我们根本不会打这种战争。”

### 阶段结尾
主角伤愈或基本恢复，得知自己不会回到原来的完整单位，而将和一批幸存骨干一起重新编入新的战斗体系。

---

# 第三阶段｜重新站起来

### 预计体量
约 47—72 章。

### 阶段任务
兑现第一次失败。

成长不能靠几句“总结经验”完成，而要让读者看见一支军队如何一点点改变自己的行为。

### 主要剧情
- 主角等人进入新的团级单位，可最终确定为后来的41团。
- 老兵、新兵、失败战役幸存者重新混编。
- 装备不是全新换代，而是大量修复、拼装、改造。
- 少爷的指挥方式发生变化。
- 老士官也发现十年前与公司的作战经验并不完全可靠。
- 帝国开始大量尝试：
  - 降低电子暴露；
  - 车辆分散；
  - 有线、定向通信；
  - 廉价无人机；
  - 假目标；
  - 诱饵；
  - 更灵活的小型任务群。

### 小剧情结构
这一阶段应该连续安排数次“差一点成功”的战斗：
1. 第一次改进后仍然失败，但死的人少了。
2. 第二次成功保住了指挥链，却没拿下目标。
3. 第三次开始真正让公司付出高价值损失。
4. 最后完成一次完整的阶段性胜利。

“假团部”战术可以放在这里作为高潮候选。

### 人物兑现
- 主角从跟着别人活下来，变成开始能帮助别人活下来。
- 少爷第一次成为士兵真正愿意服从的基层军官。
- 老士官从“老师”逐渐变成三人体系中的一员，而不是永远正确的答案机器。

### 情绪曲线
低谷 → 谨慎尝试 → 小失败 → 看见希望 → 连续进步 → 胜利。

### 阶段高潮
取得一次真正漂亮的战术胜利。

这场胜利不需要改变整个战场，但一定要让主角产生那句最重要的感受：

> “我们现在会打了。”

这是第一卷第一个明确的小高潮。

---

# 第四阶段｜拉锯

### 预计体量
约 73—102 章。

### 阶段任务
把“会打了”之后的战争真正展开。

这里是第一卷最长、最能自由生长的一段，也应该最有成熟长篇网文的感觉：不是不断升级大事件，而是多个小剧情共同组成一种长期战争生活。

### 战争态势
公司开始主动收缩外围资产，集中守卫：
- 核心矿区；
- 维修中心；
- 轨道物流；
- 山口；
- 工业堡垒。

帝国仍然推进，但速度越来越慢。

### 可放入的小剧情
- 公司真人伤员争夺。
- 战场残骸回收。
- 工业机器人临时武装化。
- 空袭申请没有获批。
- 一辆几次被修复重新送回前线的旧战车。
- 新补充兵重复主角刚入伍时犯过的错误。
- 老兵开始教新人躲无人机。
- 帝国与公司同时布置诱饵、反诱饵。
- 双方围绕一个看起来毫不起眼的维修节点付出巨大代价。

### 高层视角逐渐增加
前面中将和公司旅长只偶尔出现，这一阶段开始真正成为稳定配角视角。

中将逐渐确认：
> 公司赢了很多接触战，但帝国正在打赢整场消耗。

公司旅长则逐渐发现：
> 他每天都能得到很好看的交换比，但可以使用的高价值人员和设备越来越少。

### 人物状态
主角已经是“老兵”了。

这很重要：
第一阶段里那些让他恐惧和困惑的东西，现在已经变成下意识动作。

### 情绪曲线
胜利余韵 → 熟练 → 长期消耗 → 疲惫 → 战争常态化 → 出现新的不合理。

### 阶段结尾
中将在大量正常战报中看见一个“不该出现的数字”。

不是大败。

只是一个已经很会打公司的单位，在一个不重要的地方付出了不合理的损失。

同时，公司也在那个地方付出了不符合商业逻辑的成本。

他开始查地图。

---

# 第五阶段｜矿坑

### 预计体量
约 103—127 章。

### 阶段任务
让小说第一次从“可以理解的战争”滑向“无法理解的东西”。

转变必须慢，不能突然变成超自然副本。

### 前段
- 中将调查异常交通节点。
- 找到一座早已停产、存在感极低的地下矿区。
- 要求第三师派可靠精锐侦察。
- 第三师师长出于自身利益与对中将的不满，把41团派过去。

### 地面战
最开始仍然是完全正常的军事行动。

但公司防御强度逐渐出现问题：
- 不肯撤；
- 高价值设备投入过多；
- 真人部队开始承担平时不愿承担的风险；
- 部分公司士兵甚至不知道自己为什么必须守住这里。

### 地下战
从废弃工业设施逐渐进入更深层矿网。

异常逐层出现：
- 定位数据矛盾；
- 通信问题无法完全用干扰解释；
- 人的方向感出现偏差；
- 主角特殊感知明显增强；
- 出现无法归类为普通矿业设备的设施。

不要急着解释。

主角、少爷、老士官都只能根据自己掌握的知识猜。

### 公司侧
公司异常项目风险值守体系开始出现。

关键是：
不是某个邪恶高管拍桌子说“把他们灭口”。

一个普通值守人员只是按照手册，将风险等级一级一级推上去。

然后某个异常高等级流程直接绕过公司地面旅长。

### 人物变化
老士官第一次真正失去“经验优势”。

他熟悉战争。

但现在出现的东西已经不是战争经验能够处理的。

### 情绪曲线
任务 → 异常抵抗 → 好奇 → 不适 → 怀疑 → 恐惧 → 接近真相。

### 阶段结尾
帝国军仍在地下交火。

公司旅长仍然不知道发生了什么。

轨道上的共和国授权舰艇收到了一条特殊处置指令。

---

# 第六阶段｜一炮之后

### 预计体量
约 128—148 章。

### 阶段任务
完成第一卷最大的结构断裂：

> 地面战争突然失去意义。

### 开场高潮
遗产级空间投射发生。

- 公司没有撤自己的地面人员。
- 帝国也完全没有预警。
- 老士官死于炮击，不需要安排完美遗言。
- 少爷重伤。
- 主角依靠异常感知、地形与纯粹运气活下来。

### 炮击余波
不要马上跳政治。

先写：
- 黑暗；
- 废墟；
- 地下幸存者；
- 救援；
- 失联部队；
- 第三师寻找41团；
- 公司旅长发现自己的人也被炸死；
- 双方基层不知道战争是不是已经升级成全面战争。

### 中将线
中将快速完成最重要的军事判断：
- 停止主动进攻；
- 帝国轨道力量不得首先还击；
- 第三师只救人；
- 封存全部记录。

确认不会出现第二炮、联邦接手战略升级问题后，他回办公室睡觉。

随后得到确认：
遗产级空间投射。

皇帝已经签署最高等级弹劾程序。

### 政治与外交
视角开始明显扩大：
- 帝国军部；
- 国防体系；
- 外交体系；
- 贵族政治；
- 商业共和国；
- 联邦。

公开互相指责。

私下开始谈：
> “你要什么？”

战争结果开始被兑换成：
- 矿权；
- 资源税；
- 重建；
- 补偿；
- 驻军；
- 联邦政治资源。

### 主角视角
主角第一次发现：

他们刚刚经历的人生中最恐怖的一件事，在更高层面正在被迅速换算成数字、条约和政治利益。

### 情绪曲线
极端高潮 → 生存 → 茫然 → 战争突然停止 → 巨大反差 → 政治冷却。

### 阶段结尾
双方基本达成政治结案。

看起来战争真的结束了。

随后联邦通知：

五级事件必须接受强制技术审计。

调查员正在来外缘的路上。

---

# 第七阶段｜清算

### 预计体量
约 149—175 章。

### 阶段任务
把第一卷真正的主题翻出来：

战争结束以后，制服不再保护他们。

### 前段
幸存者最初甚至会觉得自己是英雄：
- 参加关键战役；
- 遭遇非法战略武器；
- 活着回来；
- 部队准备表彰和调查。

但事情逐渐奇怪：
- 行动受到限制；
- 通信被审查；
- 个别人员被单独带走；
- 有人试图联系联邦调查人员；
- 有人失踪；
- 档案与口径开始被统一。

### 政治逻辑
共和国不愿让炮击区一手接触者成为联邦审计中的不可控证人。

帝国已经拿到了自己想要的战争收益，也不愿重新打开地下异常问题。

压力经过多层机构向下传递。

每一层说话都比上一层文明。

最后到基层时，变成真正的抓捕与清理。

### 中将
不能洗白。

他最初反对扩大问题，也相信自己经得起调查。

但在战争收益、国家利益、个人入爵目标和政治压力共同作用下，他最终接受：

> “这件事必须结束。”

他知道自己在做什么，只是不愿追问具体手段。

### 主角
从服从审查逐渐变成怀疑。

再到：
- 保护战友；
- 营救被押人员；
- 袭击安全部门行动；
- 被重新定义为“战后极端武装”。

但不要让他突然变成反帝国革命者。

他的核心认知仍然可以是：

> “我没有背叛帝国，是这些人在背叛帝国。”

### 少爷
少爷因伤和真实军功先回到帝都。

最初他一直试图摆脱家族赋予的特权。

到了这里，他终于承认一个事实：

> 不使用特权，不会让特权消失。

为了救主角，他第一次主动进入家族政治，推动侯爵家族正式支持中将家族进入贵族席位。

交换条件只有一个：

> 主角的事情到此为止。

### 收束
中将停止主动追捕。

案件等级下降。

主角没有得到公开平反，也没有人向他道歉。

只是某一天，他突然发现：

追他的人少了。

### 第一卷结尾
主角最终离开外缘，前往帝都。

具体原因暂不锁死，可在阶段细纲中确定：
- 接受新的身份安排；
- 去见少爷；
- 配合某项调查；
- 被迫转移；
- 或其他能够自然连接第二卷的理由。

最后一个画面应该是“离开”，而不是“胜利”。

战争打完了。

他第一次离开这颗真正意义上的故乡行星。

而第二卷的舞台，从边疆战争切换到帝国中心。

# 第一卷主要人物弧线

## 主角
普通青年 → 新兵 → 失败者 → 幸存者 → 老兵 → 能独立判断的战士 → 异常接触者 → 战争英雄 → 被追捕者。

他的成长核心不是战斗力升级，而是判断力与主体性的形成。

## 少爷
军校高材生 → 教科书军官 → 经历失败 → 真正基层军官 → 战友 → 战争英雄 → 回归贵族世界 → 第一次主动使用特权。

核心变化：
> 从“拒绝特权证明自己”到“使用特权承担责任”。

## 老士官
可靠的战争经验 → 带新人活下来 → 经验被新战争不断修正 → 完成传承 → 在超出传统战争范畴的事件中死亡。

他死的时候，主角和少爷已经不再需要老师教他们如何进行一场“正常战争”。

## 中将
极强职业军人 → 用战争成本逻辑击败公司地面体系 → 达成政治军事目标 → 面对战略炮击作出正确决策 → 在战后政治中逐渐妥协 → 为人生唯一的私人目标接受脏活。

他第一卷最大的失败不是军事失败，而是：

> 他终于进入了自己并不擅长的战争。

# 第一卷的节奏约束

以下是本项目自己的工作规则，不是必须机械执行的公式。

### 1. 每个阶段都是一个“小卷”
每个约20—30章阶段至少要有：
- 一个明确阶段目标；
- 一个主要阻力；
- 若干次局部变化；
- 一次阶段性兑现；
- 一个把人物推入下一阶段的新问题。

### 2. 不要求每章都有大事件
但每章至少完成一种有效变化：
- 局势推进；
- 信息增加；
- 人物关系改变；
- 人物作出选择；
- 情绪得到兑现；
- 对后续形成期待。

连续多章都只是解释世界观或重复战况时，就说明剧情停了。

### 3. “爽点”不等于打脸
本书适合使用的阅读回报主要是：
- 战术终于奏效；
- 角色能力被证明；
- 前面埋的经验得到兑现；
- 信息突然改变读者理解；
- 人物关系发生有重量的变化；
- 高层与基层信息差形成反差；
- 一个看似合理的制度突然暴露出另一面。

### 4. 大设定不直接讲
继续遵守项目基线：

> 不写成参谋教材。

让世界观依附于人物当下正在解决的问题出现。

### 5. 第一卷的大悬念必须一直存在
战争胜负可以阶段性解决。

但矿坑与轨道炮的问题直到卷末都不能真正解释干净：

> 那里面究竟是什么？
>
> 为什么共和国认为它值得用一次最高等级违规来换？
>
> 主角为什么能够感知它？

这些问题负责把第一卷连接到更大的故事。
